📁 Base de datos en la carpeta compartida

Para que varios ordenadores vean los mismos datos, la base de datos se guarda en un archivo (pateras_datos.json) dentro de la carpeta compartida. Todos los ordenadores conectados a ese archivo leen y guardan en él, y cada pocos segundos se actualizan con lo que hayan hecho los demás.

1.º En el primer ordenador (el que ya tiene los datos)
Crea el archivo en la carpeta compartida (por ejemplo, junto al index.html). Se guardan en él los datos de este ordenador.
2.º En los demás ordenadores
Abre el archivo pateras_datos.json que creaste en la carpeta compartida.

Funciona en Chrome y Edge de ordenador. Cada vez que abras la app pedirá permiso con un clic para usar el archivo. En el móvil, Firefox o Safari no está disponible: usa «Exportar / importar».
Las copias de seguridad automáticas se guardan en cada ordenador; exporta la base de datos de vez en cuando para tener otra copia.

🗑 Borrar pateras

Marca las pateras que quieras eliminar (de cualquier año) y pulsa Borrar seleccionadas. Se borran sus personas y todo lo marcado en ellas. Antes se guarda una copia de seguridad, así que se pueden recuperar desde «Copias de seguridad».

🛡 Copias de seguridad

La app guarda copias automáticas dentro de este navegador: al abrirla (cada pocas horas), antes de cargar tablas, de eliminar una patera, de cambios en bloque, de importar o restaurar, y cada rato mientras editas. Se guardan las 30 últimas.
Ojo: si borras los datos del navegador también se borran estas copias. Exporta la base de datos de vez en cuando para tener una copia fuera.
